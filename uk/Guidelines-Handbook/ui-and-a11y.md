# UI, стилізація та доступність — Guidelines

> Рівень **Handbook**: пояснює поняття й показує, як застосовувати рішення зі
> [Standards](../Standards/index-uk.md). Правила цього рівня діють у code review, але стратегічний
> контракт — там. Реалізації — у [Reference-Recipes](../Reference-Recipes/).

## Стилізація

Деталізація `FE-UI-01` і `FE-UI-02`.

| ID | Правило | Контроль |
| --- | --- | --- |
| FE-UI-02 | Кольори та числові значення **MUST** брати з семантичних `@theme`-токенів; сирий hex/px потребує задокументованого винятку. | `eslint-plugin-better-tailwindcss` † |
| FE-UI-03 | `@apply` **MUST NOT** використовуватися; виноси `@utility` або компонент. | CI grep † |
| FE-UI-04 | Умовні та стейтові класи **MUST** складатися через `cx()` / `sortCx()` і `data-*`, ніколи через конкатенацію рядків. | review |
| FE-UI-05 | Обведення з Figma, виключене з auto-layout, **MUST** реалізовуватись як `inset-shadow` / `ring`, ніколи як CSS `border`. | review |
| FE-UI-10 | Інлайновий `style` **MUST NOT** використовуватися, окрім значень, обчислених у runtime. | review |

## API компонента

Деталізація `FE-UI-07`.

| ID | Правило | Контроль |
| --- | --- | --- |
| FE-UI-07 | Варіанти **MUST** бути окремими типізованими props або одним string-union — не конфіг-об'єктом і не набором boolean. | review |
| FE-UI-09 | Кожен експортований компонент `packages/ui` **MUST** мати поруч stories, що покривають дефолт і всі інтерактивні стани. | review |
| FE-UI-06 | Інтерактивні примітиви **MUST** будуватися на `react-aria-components`, а не на власній обробці клавіатури/фокуса. | review |
| FE-UI-08 | Спільні компоненти **MUST** віддавати `className` наскрізь і стан через `data-*`; споживачі ніколи не таргетять внутрішнє. | `eslint-plugin-boundaries » boundaries/dependencies` † + review |

## Доступність

Деталізація `FE-A11Y-01`. Кожне з цих правил — окремий success criterion WCAG 2.2 AA.

| ID | Правило | Контроль |
| --- | --- | --- |
| FE-A11Y-02 | Семантичний HTML **MUST** іти перед ARIA; `aria-*` лише там, де семантики недостатньо. | `eslint-plugin-jsx-a11y` † |
| FE-A11Y-03 | Кожен інтерактивний елемент **MUST** керуватися лише клавіатурою з видимим індикатором фокуса. | вручну |
| FE-A11Y-04 | Кожен інтерактивний елемент **MUST** мати непорожнє доступне ім'я. | `addon-a11y` |
| FE-A11Y-05 | Поля форм і їхні помилки **MUST** бути програмно пов'язані з лейблом. | `eslint-plugin-jsx-a11y` † |
| FE-A11Y-06 | Діалоги **MUST** утримувати фокус, поки відкриті, і повертати його при закритті. | вручну |
